# 🛡️ SOC Home Lab

🚧 **Status:** In progress

A home lab for practising SOC analyst skills in an isolated network.

## 🎯 Goals

- 🖥️ Set up Wazuh as a SIEM
- ⚔️ Simulate attacks against my own virtual machines
- 🔍 Investigate the alerts and logs
- 📝 Write incident reports mapped to MITRE ATT&CK

## 🧰 Tools

Wazuh | VirtualBox | Kali Linux | Ubuntu Server

## 📁 Project structure

- `notes/`: Setup notes and problems I solved
- `reports/`: Incident reports
- `screenshots/`: Evidence from the lab
